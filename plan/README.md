# 模块规划目录

此目录按模块记录需求分析、技术设计和实施验收计划。规划文档描述拟议行为，不代表功能已经实现，也不替代 `docs/subsystems/` 中描述当前行为的设计参考。

## 模块索引

## 记录规则

- 一个模块使用一个子目录，包含入口说明、需求分析、技术设计、实施与验收计划。
- 区分用户明确要求、设计建议、待确认事项和源码核验结果。
- 源码链接优先定位文件和符号，避免依赖容易失效的行号。
- 实现改变既有子系统契约时，同步更新对应的 `docs/subsystems/` 参考；不要把未实现的方案写成当前行为。
- 验证记录说明实际执行的命令、平台、结果和未验证范围，不用规划代替测试证据。
